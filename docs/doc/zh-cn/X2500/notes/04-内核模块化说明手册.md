# 简介

 本文档是基于君正发布的SDK中Linux-4.4内核进行驱动模块化编译的使用说明，适用于X2000、X2000E、X2100和M300的开发板。

# Display显示驱动模块

显示驱动模块支持的LCD类型：TFT、SmartLCD、MIPI_TFT、MIPI_SmartLCD

内核配置：
```
 Graphics support --->

[ ] Bootup logo ----> 

Frame buffer Devices ---> 

<*> Ingenic Framebuffer Driver ---> 

 [*] ingenic mipi dsi interface 

 < > Ingenic Framebuffer Driver for Version 10 ----

 < > Ingenic Framebuffer Driver for Version 11 ----

 < > Ingenic Framebuffer Driver for Version 12 ----

 <M> Ingenic Framebuffer Driver for stage ---> 

 <M> lcd panel MA0060 

 　< > lcd panel tl040wvs03ct 
```
模块加载:
```
modprobe panel-ma0060 -a
```
# Audio驱动模块

内核配置： 

```
 <*> Advanced Linux Sound Architecture ---> 

<*> ALSA for SoC audio support --->

 <M> ASoC support for Ingenic ---> 

-M- ingenic snd asoc as-fe 

-M- ingenic snd asoc baic 

<M> ingenic snd asoc spdif 

<M> ingenic snd asoc dmic 

-M- ingenic inno audio codec 

Ingenic Board Type Select ---> 

 <M> Audio support for x2100 kale board
```
模块加载: 
```
modprobe ingenic_baic
modprobe ingenic_dmic
modprobe ingenic_spdi 
modprobe snd-asoc-as-fe
modprobe icdc_inno 
modprobe snd_kale_v10 
```

# USB驱动模块

内核配置：
```
[*] USB support ---> 

 <M> Support for Host-side USB

<M> USB Mass Storage support 

 <M> DesignWare USB2 DRD Core Support

 <M> USB Gadget Support --->
```
USB控制器模块加载：
```
modprobe usbcore -a

modprobe dwc2 -a

USB-gadget 模块：

modprobe libcomposite
```
其他模块根据需要加载即可，例如在使用adb时需要加载：
```
modprobe usb_f_fs
```
# VPU驱动模块

VPU驱动分为felix和helix两部分。

felix是h264解码,包括:流解析器、运动补偿、反量化、IDCT和De-block engines的功能

helix是h264编码、JPEG压缩和解压缩

内核配置：
```
*** Multimedia core support ***

 [*] Memory-to-memory multimedia devices ---> 

 <M> 　V4L2 driver for ingenic Video Codec 

<M> ingenic video helix 

<M> ingenic video felix 
```
模块加载：
```
modprobe ingenic_felix

modprobe ingenic_helix

h264e-nl-server & 
```
注意：必须开启h264服务，否则无法进行h264编解码。

# CIM模块

内核配置：
```
 <M> SoC camera support 

 <M> platform camera support 

 <M> Ingenic Camera Sensor Interface driver 

 < > Ingenic Soc camera Driver for X1000 

 <M> Ingenic Soc Camera Driver for X2000 && M300 
```
模块加载：
```
modprobe soc_camera_platform -a
```
注意：内核设备树中默认不会使用cim节点，原有默认配置并没有编译cim相关选项，如需使用请对设备树进行相应修改。
