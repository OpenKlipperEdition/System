
## 文档归档原则
1. 以芯片型号为主
2. 只保留标准开发平台相关文档


文档结构保持以下原则
```
chip-series:                # 芯片系列: 例如 X2000,X26XX
    - chip-common 资源.      # 各芯片平台通用，只需做较少的替换就可以理解。
    - chip-board 资源          # 开发板强相关，例如：有的开发板带LCD，有的开发板带Camera。
```

## 中文文档

中文文档一律放在zh-cn 目录下面.

## 英文文档

英文文档一律放在en-us目录下

## 关于图片存储路径

md文件中对图片的索引一律以 **assets/xxxx.png** 的形式, 如果有md引用图片需求，需要在md统计目录下创建 assets目录，并将图片放在 assets目录下。


## 关于链接
一芯片为主，每个芯片的README.md文件为芯片顶层文档描述，所有芯片相关资源需要放在该目录下。
