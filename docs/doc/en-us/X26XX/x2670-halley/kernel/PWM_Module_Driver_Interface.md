# PWM module drive interface

## Module Function Introduction

The pulse width modulation (PWM) module design is divided into 16 independent channels, which can work independently without affecting each other. The square wave is generated by using the input clock source.

## Drive source code location

Location of driver source code:

***module_drivers/drivers/pwm/pwm-ingenic-v3.c***

### Default configuration of device tree

Taking X2660 halley v1.0 as an example, in the kernel board-level configuration file, the kernel defaults to enabling pwm devices on LCD device trees that are compatible with development boards, such as in X2660_HALLEY_MIPI_LCD_FW050.dtsi

```c
&pwm {

    pinctrl-names = "default";

    pinctrl-0 = <&pwm10_pe>;

    status = "okay";

};
```

### Device tree custom configuration

If you need to use GPIO of other channels as PWM output, you can modify the dtsi file that belongs to the LCD configured by the current development board under ***module_drivers/dts/x2660_halley_ LCD/***. Take II as an example, add the pwm12_pc:

```c
&pwm {

    pinctrl-names = "default";

    pinctrl-0 = <&pwm10_pe>,<&pwm12_pc>;

    status = "okay";

};
```

## Device Node Generation

You can check the specific situation of pwm devices through `standard/sys/class/pwm`, and export and use pwm in user space through standard sysfs interface.

### Export of core PWM standard framework

When users use the kernel pwm standard framework, they can operate in the "sys/class/pwm/pwmchip0/" path. First of all, users can cat the npwm file to view the number of supported pwm channels, for example x2660 halley v1.0:

```
# ls

device export npwm power subsystem uevent unexport

# cat npwm

16
```

X2660 supports 16 PWM channels.

Users can write the required channel number to the export file, which will generate a pwm* folder. Under this folder there are files corresponding to the operation of pwm channels.

```
# echo 12 > export

# ls

device npwm pwm12 uevent

export power subsystem unexport

# cd pwm12/

# ls

duty_cycle enable period polarity power uevent
```

period：This file is used to set the period, and the unit is ns.
duty_cycle: This file is used to set duty cycle (positive duty cycle), and the unit is ns.

Polarity: This file is used to set the polarity, that is, whether the low level or high level represents the open state. Generally, it's "normal", which means the high level represents the open state (inversed, normal).

enable: This file is used to enable or disable pwm output.

When setting the period and duty cycle, the period must be set before the duty cycle, otherwise an error will occur.

When pwm channels are not needed, users can import pwm channel numbers to unexport file and close pwm related configuration files.

```
# ls

device npwm pwm12 uevent

export power subsystem unexport

# echo 12 > unexport

# ls

device export npwm power subsystem uevent unexport
```

## Application Instructions

### Test methods

1. Enter the directory under `sys/devices/platform/ahb_mcu/13610000.pwm/`:

```
# ls

channels finish_level of_node sg_pwm_num

driver free period_ns subsystem

driver_override init_level power trigger

duty_ns modalias pwm uevent

enable mode request
```

2. By writing 0~15 to request, you can export the corresponding pwm for use. Here is an example using pwm12:

```
# echo 12 > request
```

3. Then it can be seen that 12 channels under channels have been applied, and other channels are similar:

```
# cat channels

ch: 00 unrequested

ch: 01 unrequested

ch: 02 unrequested

ch: 03 unrequested

ch: 04 unrequested

ch: 05 unrequested

ch: 06 unrequested

ch: 07 unrequested

ch: 08 unrequested

ch: 09 unrequested

ch: 10 unrequested

ch: 11 unrequested

ch: 12 requested

ch: 13 unrequested

ch: 14 unrequested

ch: 15 unrequested
```

4. Set the period to 100,000 with a unit of nanoseconds:

```
# echo 100000 > period_ns
```

5. Set the duty cycle to 50,000 with a unit of nanoseconds:

```
# echo 50000 > duty_ns
```

6. Enable pwm12:

```
# echo 1 > enable
```
If set correctly, there will be corresponding waveform output at this time.

7. If you stop using echo channel number > free, you can turn off waveform output.

```
# echo 0 > free
```
