# X26XX Documentation Repository Introduction

This repository contains documents that can be used for the X2670 series and X2600 series chips, providing guidance in areas such as chip startup, driver development, board-level configuration, and application development.

## X26XX Series Chip Introduction
The X26XX series chips include:
- X2670
- X2600
