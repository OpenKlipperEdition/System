# 预留内存配置说明

## 1. 简介

Linux内核设备树中存在一项***reserved-memory***配置。它被用来在设备树中定义一段预留内存，并让**指定的**操作系统或驱动程序使用这段内存区域，用以避免在运行时发生内存冲突或其他问题。

在设备树中启用reserved-memory后，可以通过memory-region参数将预留的内存空间分配给特定的设备驱动程序使用。

## 2. 配置方法

以x2600 halley v1.0为例

### 2.1 在设备树中添加reserved-memory

打开开发板设备树，路径为：

```
module_drivers/dts/x2600_halley_v1.0.dts
```

1. 在设备树中添加reserved-memory节点，并指定reserved-memory的属性

```c
reserved-memory {
        #address-cells = <1>;//地址单元数量：1
        #size-cells = <1>;//大小单元数量：1
        ranges =<>;//描述预留内存的具体范围，这里为空，在下文中设置

}
```
2. 在reserved-memory节点中添加配置

```c
reserved-memory {
        #address-cells = <1>;
        #size-cells = <1>;
        ranges =<>;

        reserved_memory: reserved_mem@0x6000000{
              compatible = "shared-dma-pool";
              reg = <0x06000000 0x2000000>;//内存区域的大小和起始地址。
        };
}
```
3. 将预留内存分配给驱动

以 ***felix***（h264硬件解码驱动）为例，将预留内存分配给 ***felix***，在felix设备树中添加memory-region，并指定memory-region的属性。

```c
&felix {
        status = "okay";
        memory-region=<&reserved_memory>;
};
```
### 2.2 在驱动代码中分配预留内存

包含预留内存分配函数的文件路径

```
include/linux/of_reserved_mem.h
drivers/of/of_reserved_mem.c
```

felix驱动代码路径：

```
module_drivers/drivers/media/platform/ingenic-vcodec/felix/felix_drv.c
```

1. 在felix驱动代码中包含预留内存分配函数的头文件

```c
#include <linux/of_reserved_mem.h>
```

2. 在felix驱动的probe函数中引入分配设备树预留内存配置的函数

```c
static int ingenic_vcodec_probe(struct platform_device *pdev)
{
int ret;
...
...
ret = of_reserved_mem_device_init(dev->dev);
if(ret)
dev_warn(&pdev->dev, "failed to init reserved mem\n");
...
...
return 0;
}
```

至此预留内存配置完成，保存修改后编译并烧录内核镜像。

### 2.3 启动内核，查看预留内存是否分配成功

当出现如下内核启动打印时，felix预留内存分配成功

```
Reserved memory: created DMA memory pool at 0x06000000, size 32 MiB
Reserved memory: initialized node reserved_mem@0x6000000, compatible id shared-dma-pool
```
```
felix-vdec 13300000.felix: assigned reserved memory node reserved_mem@0x6000000
```

## 3. 总结

目前为止，在X26xx Linux内核中被分配预留内存的驱动为DPU、Felix、Jpegdec、Jpegenc、RISC-V。

## 4. 注意事项

在一般情况下，要分配的预留内存大小不要超过DDR容量的1/4，因为预留内存的大小会影响到DDR的可用空间，预留内存过大会导致内核启动失败、系统分配内存失败等问题。
