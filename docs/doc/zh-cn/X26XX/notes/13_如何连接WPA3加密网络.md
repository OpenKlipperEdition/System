#  如何连接WIFI WPA3加密网络
## 软件和硬件检查
    1、检查Linux内核版本和wpa_supplicant版本是否符合要求
    2、检查无线网卡硬件和驱动程序是否支持WPA3
    版本通常需要linux kernel > 5.4，wpa_supplicant > 2.9
## 在kernel中添加wifi驱动支持 
1、将要使用的wifi的驱动移植到kernel5.10对应目录下，编译，烧录，启动；
并通过串口打印以及ifconfig -a 命令确定网卡驱动是否加载成功

## 修改wifi配置文件以支持wpa3连接
修改默认配置文件:/etc/wpa_supplicant.conf
```txt
ctrl_interface=/var/run/wpa_supplicant
update_config=1
country=GB"

network={
    ssid="wifi账号"
    psk="wifi密码"
    key_mgmt=SAE
    ieee80211w=1
    priority=1
}

```
