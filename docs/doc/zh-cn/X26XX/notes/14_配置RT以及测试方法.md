# linux RT patch配置和测试

## 内核编译配置

```
Symbol: PREEMPT [=y]
Type  : bool
Defined at kernel/Kconfig.preempt:58
  Prompt: Preemptible Kernel (Low-Latency Desktop)
  Depends on: <choice> && !ARCH_NO_PREEMPT [=n]
  Location:
    -> General setup
      -> Preemption Model (<choice> [=y])
        -> Preemptible Kernel (Low-Latency Desktop) (PREEMPT [=y])
Selects: PREEMPT_BUILD [=y]

		   No Forced Preemption (Server)--主动吞吐量，对时间不敏感场景，比如服务器。
		   Voluntary Kernel Preemption (Desktop)--牺牲小部分吞吐量，增加更多抢占点，降低延时提高了响应速度。适用于桌面环境。
		   Preemptible Kernel (Low-Latency Desktop)--将非关键部分内核代码都变成可抢占，提高了响应速度。适用于对延时有一定要求的桌面和嵌入式设备。
		   Automagic preemption mode with runtime tweaking support--自动调整内核的抢占等级（preemption level），以达到最佳的实时性能。
		   Fully Preemptible Kernel (Real-Time)--将内核中不可抢占部分修改，除了底层和关键代码不可抢占以外，全可抢占。适用于需要保证实时性的场景。
```

根据需要选择不同的抢占模式。

选择后可在命令行输入“uname -an” 查看

```
# uname -an
Linux buildroot 6.6.18+ #6 SMP PREEMPT Fri Sep 20 11:39:13 CST 2024 mips GNU/Linux

# uname -an
Linux buildroot 6.6.18-rt23+ #1 SMP PREEMPT Wed Sep 25 17:26:55 CST 2024 mips GNU/Linux

# uname -an
Linux buildroot 6.6.18-rt23+ #4 SMP PREEMPT_RT Thu Sep 26 16:47:18 CST 2024 mips GNU/Linux
```

以上分别为没有安装补丁没有修改抢占模式、打了补丁但没有修改抢占模式、打了补丁且修改为了实时RT模式。

### 工具使用说明

```
# cyclictest -p 80 -t 8 -q -l 40000

创建 8 个线程（优先级为 80）线程，每个以 40 毫秒的期望执行时间运行，在结束时输出总结信息。
参考avg、max（平均响应时间、最大响应时间），用于评估系统的实时性能
```

```
latencytop

显示系统中每个中断源的最大延迟、平均延迟和其他统计信息。
```

```
# stress --cpu 2 --io 2 --vm 2 --vm-bytes 32M

启动两个 CPU 负载进程、两个 I/O 负载进程和两个内存负载进程，每个内存负载进程占用 32MB 的内存。
使用这条命令可以模拟 CPU、内存、磁盘和网络负载，作为压力测试。
```
