# 看门狗测试介绍

## 简介

本测试主要用来测试看门狗是否正常工作。

## 目录结构

```
.
├── ihal_config.h       # 自定义配置文件
├── Makefile            # 编译文件
├── README.md           # 说明文件
└── watchdog_test.c     # 测试文件
```

## 测试自定义配置

在 ***ihal_config.h*** 文件中可以自定义配置看门狗的参数，具体配置如下：

```c
#define WATCHDOG_DEV_NODE "/dev/watchdog0"	/* 看门狗设备节点路径 */
#define TIMEOUT 10				/* 超时重启时间，单位：秒 */
#define FEED_TIME 3				/* 喂狗间隔时间，单位：秒 */
```

## 测试流程

1. 初始化看门狗
2. 设置超时重启时间
3. 启动看门狗
4. 喂狗
5. 停止看门狗
6. 关闭看门狗

## 测试结果

进行喂狗操作后会打印 “***feed dog***”，两秒后关闭看门狗

## 注意事项

测试用例中在喂狗操作完成后延时2秒才停止看门狗工作，所以在 **本测试中** 设置 *看门狗超时重启时间* 和 *喂狗间隔时间* 要适当，否则将不会出现正常测试结果。
